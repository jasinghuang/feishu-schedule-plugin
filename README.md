## 📋 三张数据表

| 表 | 作用 | 关键字段 |
|---|---|---|
| **档期预约** | 核心表：每周 4 位摄影师 × 10 个半天 = 40 条"档位格子" | 周次、摄影师、星期、时段、日期、请假、预约主播、状态(公式)、本周标记(公式) |
| **摄影师** | 5 位摄影师池，"本周上岗"勾选 = 5 选 4 | 姓名、擅长方向、本周上岗 |
| **周汇总** | 每周每人的完成视频数 = 归档快照 | 周次、摄影师、上岗、完成视频数、归档时间 |

## 👀 档期预约表的三个视图

| 视图 | 复刻自 | 逻辑 |
|---|---|---|
| **本周预约看板** | 预约看板矩阵 | 「本周标记」公式字段基于 `TODAY()` 自动滚动，永远只显示当前周的 40 个档位；按摄影师分组，按星期+时段排序。**主播直接在"预约主播"列填名字即占坑，清空即释放** |
| **历史归档** | 历史归档库 | 自动排除本周，按周次倒序分组，所有历史预约与档期永久保留 |
| **全部档期** | — | 无筛选全量视图，方便批量管理 |

> 状态列公式：`IF(请假,"请假",IF(预约主播="","可约","已约"))`（与网页版绿/紫/灰三态一致）
> 每位摄影师每周限约 2 个半天的规则由人工把控（多维表格视图无法硬性拦截，可在看板上按摄影师组内一眼数出已约数）。

## 🔄 归档并生成下周（每周五下班前跑一次）

```bash
cd "E:\work\信息流视频拍摄\feishu-schedule-build"
node roll-week.mjs          # 自动轮换：本周轮休的摄影师下周上岗（推荐，同网页版默认策略）
node roll-week.mjs --keep   # 沿用本周 4 位阵容
```

脚本会自动：追加新"周次"选项 → 生成下周 40 条档位 → 创建周汇总空行（等摄影师填完成视频数）→ 更新摄影师表"本周上岗"勾选。已有该周档期时会自动中止，不会重复。

其他参数：`--week 2026年第50周 --monday 2026-12-07`（指定周）、`--photographers "姓名A,姓名B,姓名C,姓名D"`（指定名单）、`--no-duty-update`（只铺数不动勾选）。

> 当前已预生成到 **2026年第49周**（11/30–12/04），下次需要跑是 11/27（周五）生成第 50 周。

## 🚫 不可约时段标记 + 限约2档（2026-11-12 新增）

- **摄影师表 →「不可约时段标记」视图**：左列摄影师，横向 周一上午…周五下午 10 列公式格（显示 可约/已约/请假），尾部"本周已约数"。数据经 **双向关联字段** 实时取自档期预约表——在档期表勾"请假"或填主播名，此矩阵秒级同步。
- **限约2档守卫自动化**（workflow `wkf0XDFW4e8gJzdg`）：当"预约主播"被填写且该摄影师本周已约数≥3 时，自动清空本次填写。已实测：连约 3 个半天，第 3 个被自动清退。
- 档期预约表新增公式列「该摄影师本周已约数」（经关联链取摄影师表统计）。
- ⚠️ 摄影师改名流程：改摄影师表"摄影师"后，需同步改档期预约/周汇总"摄影师"单选的选项名（或用 roll-week 前先统一）。
- 档期预约/周汇总的"摄影师"为**普通单选**（动态选项源已废弃——动态源+跨表公式不兼容）。
