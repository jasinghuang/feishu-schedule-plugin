## 数据如何协作

| 数据 | 唯一维护位置 | 插件行为 |
| --- | --- | --- |
| 日期、时段、主播、参与摄影师、脚本、实拍条数 | 每周排期 | 直接读写同一条记录 |
| 摄影师名单、本周上岗 | 摄影师表 | 排班页直接读取名册、调整本周上岗 |
| 摄影师表的已约数、时段占用 | 从每周排期计算的公式 | 与插件排班使用同一来源 |
| 请假 | 档期预约的请假字段 | 排班时段设置中更新 |
| 团队该周完成拍摄 | 每周排期的实拍条数 | 按记录 ID 去重求和 |
| 摄影师当周完成拍摄(条) | 从每周排期计算的公式 | 自动汇总参与的拍摄条数 |

一条记录是一位主播的一场拍摄。同一时段可以安排不同摄影师拍不同主播；协作拍摄在「暂定摄影师」里多选，脚本与条数仍只有一份。插件只保留「按拍摄查看」「摄影师排班」两个 tab，初次默认按拍摄查看。排班页选择摄影师后查看个人半天安排，多个入口打开同一条拍摄记录。摄影师个人参与条数可能重叠，不能相加作为团队产量。

每周五 17:00（Asia/Shanghai），飞书工作流为下周一至周五逐日查重：当天已有任意排期则跳过，没有才新增一条仅含日期的空白行。「按拍摄查看」显示日期有效的空白行，点击「填写排期」选择主播、时段并填写脚本或参与摄影师，保存更新原记录。未填写主播的空行不计入场次、产量或摄影师占用。

「按拍摄查看」在每天日期行右侧提供「新增拍摄」，打开表单时默认使用当天日期，仍可修改日期。周一至周五即使没有记录也会显示日期分组；已有周末拍摄继续显示。日期分组仅用于展示，不会自动创建记录。「新增拍摄」可在同一天、同一半天安排多场，由不同摄影师分别参与。第一场优先使用当天完全空白且可编辑的日期模板；有准备资料的草稿会保留，已有场次不会覆盖，后续场次新增独立记录。同一摄影师同一半天仍限参与一场；协拍在同一场次里多选摄影师。只有具备新增权限的账号显示此入口。

排班空闲时段「＋」只允许加入该日期、该半天已有且已填写主播的场次或请假；同一时段有多场时分别列出加入按钮。加入只增加原记录的参与摄影师，不创建拍摄、不复制脚本或条数。已约格可编辑同场记录，已请假格可取消请假。「本周上岗」开关只显示在当前周，历史或未来周不显示当前上岗设置。

新建请假同步保存摄影师关联与日期对应的星期，原表和插件共用同一条请假记录；取消请假保留该记录。原表「本周标记」包含完整周一至周日，与插件周范围一致。

插件不再写入「档期预约 / 预约主播」，不依赖旧状态公式或周汇总表。启动、刷新、切周均只读；自动建行由飞书服务端工作流执行，无需打开插件，不归档或清空旧记录。每周排期现有视图的字段顺序、分组、筛选、排序及样式保留。

飞书表内直接修改会触发插件重新读取当前周；插件保存直接更新每周排期。脚本为一个文本字段，可保存链接或正文。实际条数留空表示未填报，0 表示已填报为零。列表页与场次详情弹窗均提供「删除该场次」入口，仅适用于未填报实拍条数的场次（已填报记录的详情页按钮禁用并提示不可删除）。删除周一至周五当天唯一一条记录时，插件清空主播、时段、摄影师与脚本并保留该日期空白行，避免该天从飞书表格消失；同日有多场或周末场次则直接删除该条记录。移除单个协作摄影师请编辑参与摄影师。

## 权限与规则

面向摄影师使用，沿用当前飞书账号的表、记录及单元格权限；前端不持有应用密钥或访问令牌。不会扩大 Base 分享范围。没有编辑权限时只读。主播不使用插件。

保存预约前核对同一摄影师同一半天的冲突、请假、本周轮休及每周最多两个半天。历史补录不受两个半天限制。直接在飞书表里编辑不会经过插件的预约校验；插件排班会标出已存在的冲突。多人同时修改同一字段时，保存前检测已发生的冲突；飞书 SDK 不提供原子比较并写入，不能保证两次完全同时提交的排他性。

## 开发与验证

以下命令从项目根目录运行。

```sh
node --test tests/*.test.mjs
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/schedule-plugin.html?preview=1` 查看纯合成数据演示。演示模式仅允许 localhost/127.0.0.1；正式页面独立打开时明确提示从飞书进入，不会悄悄回退为本地数据。

## 目录

```text
feishu-schedule-plugin/
├── README.md                 项目入口
├── schedule-plugin.html      飞书注册入口
├── schedule-app.mjs          界面与交互
├── schedule-data.mjs         SDK 权限、分页与读写核验
├── schedule-core.mjs         日期、预约校验与去重统计
├── schedule-refresh.mjs      保存与事件刷新的合并调度
├── schedule.css              界面样式
├── sdk/                      随站点托管的飞书 SDK
├── config/                   当前飞书公式与工作流定义
├── docs/                     Base 配置和发布说明
├── tests/                    合成预览与回归测试
└── private/                  本地材料，Git 忽略
    ├── README.md             私有材料索引
    ├── backups/              升级与名册迁移前后快照
    ├── history/              按日期保存的修复、审计与验收记录
    ├── previews/             历史界面预览
    └── screenshots/          独立验收截图
```

运行文件保留在根目录，直接静态发布，无构建步骤或新增运行依赖。`config/` 中的 JSON 是配置记录，须通过飞书维护操作才能应用；插件不会在启动时执行它们。`private/` 含真实记录，不得提交或对外提供静态访问；每次操作的快照、结果及关联预览放在同一个日期主题目录内。

只读取所选周的排期和请假，摄影师名册单独读取；事件变更合并刷新，避免扫描全部历史。

新建查空白模板只读取主表；保存校验重新读取该周拍摄、名册与请假，展示权限只在界面刷新时读取。记录、字段和权限变化按事件类型处理；保存期间的通知合入保存后刷新，读取期间或稍后收到的新事件继续刷新。逐字段写入权限、并发比较和保存后读回保持执行。

Base 公式与同名引用注意事项见 [Base 配置](docs/BASE_SETUP.md)，上线步骤见 [发布说明](docs/DEPLOY.md)。

界面固定使用 Wise 色系的单一浅色主题（近黑文字、青柠绿、白色与淡灰绿），支持窄屏排班。选择摄影师和调整上岗分别操作；保存、加入和请假均提供等待反馈，成功提示不改变页面布局，失败保留原弹窗和输入。
